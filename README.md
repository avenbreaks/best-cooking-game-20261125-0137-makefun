**Dapur Kilat** — a fast warung cooking game: orders land on the board, you chop on the talenan, fry on the wajan, assemble the plate and serve before the customer walks away. Five warung dishes, a 150-second shift, 3 hearts, combos for fast serves, and a rush in the last minute.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — keyboard and mouse. Keys: 1–6 pick an ingredient, C chops, F works the wok, S serves, T clears the plate, P pauses.
